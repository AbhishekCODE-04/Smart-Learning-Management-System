# Smart Learning Management System

A basic Java-based Learning Management System designed to manage students, teachers, courses, assignments, assessments, and learning resources.

## Problem Statement

Educational institutions face difficulties in managing digital learning resources, assignments, assessments, and student engagement. This project aims to provide a centralized LMS using Java and Object-Oriented Programming concepts.

## Objectives

- Manage student and teacher information.
- Organize courses and learning resources.
- Manage assignments and assessments.
- Track student performance.
- Apply Java OOP concepts in a real-world project.

## OOP Concepts Used

- Classes and Objects
- Constructors
- Inheritance
- Abstraction
- Interfaces
- Polymorphism
- Method Overloading and Overriding
- Arrays
- Lambda Expressions
